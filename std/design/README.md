# std/design/ — 标准库设计文档

## 写作规范

每篇文档必须包含：**范围**（哪些模块/API）、**公开 API 面**（签名级）、**所有权与生命周期**
（谁分配、谁释放、是否可拷贝）、**错误契约**（`?T` 还是 panic）、**确定性要求**（迭代顺序等）、
**依赖**（只允许依赖 `std` 内模块）、**测试用例清单**、**开放问题**。

未写完设计的模块不进入实现；实现与文档不一致时以文档为准并立刻回填。
